Onde cada escolha fica

No servidor (data/avisos.json): eventos e horário de silêncio. Valem em qualquer aparelho e o push da camada 2 filtra por eles.

No navegador (localStorage): som, vibração, tela acesa. Cada aparelho tem o seu.

Padrão da central

Quem nunca abriu esta tela recebe o padrão definido no PC principal (⚙ Configurações · Avisos). Só o que a pessoa muda fica gravado para ela. "Voltar ao padrão" apaga as diferenças.

Turnos

Hoje o programa não tem turno. Os botões de turno só preenchem o horário de silêncio. Se o estudo 05 criar turnos de verdade, esta escolha passa a apontar para eles.
