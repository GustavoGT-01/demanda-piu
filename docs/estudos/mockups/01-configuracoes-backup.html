O que vai acontecer
  1. A cópia escolhida é conferida (hash ✓). Se tiver defeito, nada muda.
  2. Antes de trocar, é feita uma cópia de segurança do estado atual ("antes de restaurar"). Dá para desfazer por ela.
  3. Os dados são trocados. Os números SOL-n continuam a partir do maior já usado (o próximo é o SOL-5235). Nenhum número se repete.
  4. As pessoas nos celulares e tablets voltam para "Quem é você?" e digitam o código de novo. Os aparelhos não precisam do PIN de novo.
  5. As telas abertas se atualizam sozinhas em até 3 segundos e mostram o aviso "Dados restaurados para 27/10 12:00".
